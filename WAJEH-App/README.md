## WAJEH App

WAJEH is an Android mobile application designed to help individuals improve their communication skills and build confidence in interviews, presentations, and public speaking scenarios. The app provides a structured, supportive environment that combines guided exercises, live professional sessions, and AI-powered speech analysis.

### Key Features
- Live audio/video training sessions with certified specialists
- Guided 4-7-8 breathing exercises to reduce anxiety and stress
- Arabic speech recording and analysis using Azure Speech-to-Text
- Detailed feedback on speech pace, wording, and patterns
- Gamified social challenges and word-unscramble mini-game
- Points-based reward system with in-app wallet
- Progress tracking dashboard (scores, skill level, daily summary)
- Admin dashboard for managing users, specialists, and reports

### System Architecture
- Model–View–ViewModel (MVVM) architecture
- Clear separation between UI, business logic, and data layer
- Scalable design supporting Trainee, Specialist, and Admin roles

### Technologies Used
- Flutter (cross-platform mobile development)
- Dart
- Firebase (Authentication, Cloud Firestore, Storage)
- Azure Speech-to-Text (Arabic language support)
- Agora API (real-time audio/video calls)
- Stripe API (secure payment processing)
- GitHub (version control)
- Trello (project management)
