## ClubSphere

ClubSphere is a web-based system designed to manage and organize university clubs and their activities through a centralized digital platform. The system allows students to explore clubs, view activities, and stay informed about events, while enabling club administrators to manage memberships, announcements, and activity details efficiently.

ClubSphere aims to enhance student engagement, improve communication between clubs and members, and streamline the management of university club activities within an organized and accessible web environment.
## Languages Used
- HTML
- CSS
- JavaScript
- PHP
